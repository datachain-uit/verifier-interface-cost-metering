# Analysis: values, tables and figures

| Generator | Reads | Writes |
|---|---|---|
| `derive_values.py` | frozen packages only (`provenance/PACKAGES.tsv`), each manifest and each file read hash-checked | `generated/article-values.tex`, `generated/article-values.tsv`, `generated/data/*.csv`, `generated/MANIFEST.json` |
| `tables/src/make_tables.py` | `generated/data/` | `tables/T1-regimes.tex`, `T2-structure.tex`, `T3-tests.tex`, `TABLES-MANIFEST.json` |
| `supplement/src/make_supplement_tables.py` | frozen protocol, scoring and evidence files (each checked against its package manifest) and `generated/data/` | `tables/supplement/S01`–`S25`, `SUPPLEMENT-MANIFEST.json` |
| `figures/src/build_figures.py` (with `figstyle.py`, `fig2_design_map.py`, `fig3_crossovers.py`, `fig4_prediction.py`, `fig5_prover.py`) | `generated/data/` | `figures/Fig2`–`Fig5` (`.pdf`, `.svg`), `figures/FIGURES-MANIFEST.json`; verifies the Fig. 1 export record |

Rules that hold for all four: no refit, no re-scoring, no change of a tolerance or a registered rule, no P0 input to any
reported value; the tables and figures compute no scientific quantity (display transforms only); every run is
deterministic and `--check` compares a fresh build with the committed outputs byte for byte. Run them from the
repository root, in the order above, or use `scripts/regenerate-outputs.sh`.

Generator paths written in output stamps (`% GENERATED by tables/src/make_tables.py …`) and in the three output
manifests are relative to this directory.

`generated/article-values.tsv` lists, for every value key, the LaTeX value, the raw value, the unit and the frozen source
(`package:file:field`). Package names are those of `provenance/PACKAGES.tsv`; file names inside frozen packages are kept
as frozen.
