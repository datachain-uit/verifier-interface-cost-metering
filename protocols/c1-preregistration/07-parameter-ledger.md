# 07 — Parameter ledger (V2-C1, frozen)

Machine-readable ledger: `07-parameter-ledger.csv` (generated by `model/make_ledger.py` from the static rows in that
script and the fitted values in `09-numeric-predictions/fitted_parameters_and_tolerances.json`).

Columns: `symbol, meaning, environment, depends_on_backend, depends_on_k, source_type, source, calibration_cells,
fitted, used_for_held_out, value_P, uncertainty, notes`.

## Source types

| Source type | Meaning | Examples |
|---|---|---|
| analytic (template) | read from the snarkjs 0.7.5 templates; exact; checked by Level-1 structural checks | n_ecMul, n_ecAdd, n_pair, ρ_b(k), ncalls_b(k) |
| analytic (frozen corpus) | computed from the frozen proofs before any run | calldata bytes and zero bytes of every transaction |
| spec | Ethereum EIPs / Yellow Paper | EVM gas schedule (Osaka, Petersburg) |
| source code | pinned VM source | ZKsync OS v0.4.0 native table, precompile and keccak natives |
| P0-measured | per-call quantities measured once in P0 (not fitted) | EraVM frame costs per precompile call, EraVM keccak 119 + 40/round |
| P0-calibrated | fitted on P0 cells at k ∈ {1, 4} only | A, B for EVM Osaka / Petersburg and EraVM v29 (set P) |
| smoke-calibrated | fitted on the v32.0 smoke check, k = 1 | base_zk, c_zk (set P) |
| registered-calibrated | fitted on registered calibration cells only | A, B (procedure R); base_zk, c_zk (procedure R) |
| P0-derived (criteria) | tolerances and equality bands | τ, τ_cond, ε |

## The ZKsync OS "two constants fitted at k = 1" (owner question)

- **Which backends:** Groth16 and PLONK, k = 1 only (the exact V1 relation, circuit `c1_k01`), npg = 100.
- **Shared or specific:** one `base` and one per-call `c` for **all** templates and all k.
- **How:** the measured native minus the published-table trace native T(trace) gives one residual per template;
  two residuals, two unknowns (ncalls = 3 for Groth16, 37 for PLONK), exactly identified. Set P uses the smoke-check
  proof j0 of each template (with its P0 EDR trace); procedure R uses the mean residual over j = 0…7 of the registered
  k = 1 cells.
- **Why FFLONK is legitimately held out:** no FFLONK value enters base, c, the table or the model form, which are all
  frozen here before any d = 11 FFLONK measurement; FFLONK's call count (13), EC mix and field-arithmetic volume differ
  from both calibration templates.
- **Forbidden inputs:** the measured native or gas of the predicted cell or any other non-calibration cell; any FFLONK
  native; any ZKsync OS measurement at k ≠ 1; post-hoc changes to the table, ncalls, ρ or the model form; re-choosing
  the calibration cells. Allowed: the EVM opcode trace of the same proof (independent meter) and the frozen corpus.

## Held-out use

`used_for_held_out = yes` means the parameter enters predictions of held-out cells; the calibration cells listed
for it are the **only** data from which it may be estimated (`08-calibration-heldout-matrix.csv`).
