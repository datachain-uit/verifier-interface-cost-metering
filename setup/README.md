# Setup material

| Directory | Content | Manifest |
|---|---|---|
| `ptau/pot16_final.ptau` | powers-of-tau file (power 16, one contribution, generated by the authors for measurement; not a trusted setup) used by the C1 Groth16 / PLONK setups and the prover analyses; SHA-256 pinned in `protocols/c1-preregistration/toolchain/PINS-C1.txt` | `prover-objects/ARTIFACTS.sha256` |
| `prover-objects/` | circuits (depth 5–15), R1CS files, Groth16 proving and verification keys, PLONK verification keys, witness generators, verifier contracts, public inputs and proofs, setup scripts and constraint counts used by the prover analyses. The 11 PLONK proving keys are regenerated (`provenance/REGENERABLE.tsv`) | `ARTIFACTS.sha256` |
| `fflonk/` | FFLONK setup outputs: verification keys, Solidity verifiers, proofs, setup and proving logs, the records of the research powers-of-tau (power 19) and of the FFLONK setup run | `TRANSFER-SHA256SUMS`; workstation hashes in `records/FFLONK-ARTIFACTS-SHA256SUMS` and `ptau-local/PTAU-LOCAL-SHA256SUMS` |
| `fflonk/compiled-verifiers/` | compiled FFLONK verifiers and the repeated off-chain proof check | `SHA256SUMS` |

The research powers-of-tau of power 19 and the four FFLONK proving keys are classified `GIT-LFS` in
`provenance/OBJECT-CLASS.tsv` (see the top-level README, sections 16 and 17).
